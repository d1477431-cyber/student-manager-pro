# 🎓 Student Manager PRO (v2.1.0)

Une application professionnelle de gestion des étudiants développée en Python avec Tkinter.

## ✨ Nouveautés de la v2.1.0

- **Interface Ultra-Moderne** : Design Midnight Blue avec animations fluides.
- **Tableau de Bord** : Statistiques en temps réel et graphiques analytiques (Matplotlib).
- **Gestion Financière** : Suivi des paiements et génération de reçus PDF.
- **Architecture Hybride** : Supporte SQLite (local) et MySQL (serveur).
- **Sécurité** : Système de login, hachage des mots de passe et journal d'audit (logs).
- **Multi-thèmes** : Plus de 10 thèmes disponibles (Dark, Nature, Cyber, Luxury...).

## 🚀 Installation

```bash
pip install -r requirements.txt
python gestionnaire.py
```
